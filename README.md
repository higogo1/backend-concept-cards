# 백엔드 개념 카드

백엔드 필수 개념 68개(HTTP·네트워크, API 설계, 데이터베이스, 인증·보안, 아키텍처, 성능·운영)를 외우는 학습 사이트입니다.

- **개념 익히기**: 분야별 필터와 검색
- **카드 뒤집기**: 용어 ↔ 설명 카드를 뒤집고 알았음/몰랐음 체크 (Space, ←, →)
- **퀴즈**: 4지선다, 설명→용어 / 용어→설명 / 섞어서 (1–4, Enter)
- **오답노트**: 틀린 개념 자동 수집, 2번 연속 맞히면 졸업

학습 기록은 브라우저(localStorage)에 저장됩니다. 빌드 없이 `index.html` 하나로 동작합니다.
